## What changed

### Shared intent-state helpers (`lib/features/common/reminder_intent_state.dart`, `strings.dart`)

- Reused `StoredReminderState`, `storedReminderState`, `storedReminderMessage`, and
  `reminderRowSubtitle` from batch 5 without duplicating any 24-hour cutoff or deadline logic.
- Added `K.storedReminderCount(int n, AppLang lang)` (`০টি সংরক্ষিত রিমাইন্ডার` /
  `0 stored reminders`, `১টি সংরক্ষিত রিমাইন্ডার` / `1 stored reminder`, etc.) in
  `lib/features/common/strings.dart`.
- Added `storedRemindersSummarySubtitle({required reminderIds, jobs, required now, required lang})`
  in `lib/features/common/reminder_intent_state.dart` to derive the Settings summary subtitle from
  `UserPreferences.reminderJobIds` and the current feed jobs using the existing intent-state copy.
  No label claims that a notification was scheduled, delivered, or missed.

### Calendar (`lib/features/calendar/calendar_screen.dart`)

- Every calendar deadline card whose job ID is in `UserPreferences.reminderJobIds` now renders
  `reminderRowSubtitle(job: entry.job, now: now, lang: lang)` under its deadline label in addition
  to the read-only bell icon.
- Existing closing-soon / expired deadline grouping, accent colors, and live `DeadlineTicker`
  updates are untouched; crossing the 24-hour cutoff updates the subtitle live from `pending` to
  `duePassed`.

### Saved (`lib/features/saved/saved_screen.dart`)

- Subscribes to `widget.preferences.reminderJobIds` alongside `savedJobIds`.
- Every resolved saved `JobCard` with a stored reminder intent renders `_SavedReminderSubtitle`
  with `reminderRowSubtitle(job: job, now: now, lang: lang)` directly underneath, covering
  `pending`, `duePassed`, `closed`, `withdrawn`, and `noDeadline` states.
- Every missing saved job (`UnavailableJobTile`) whose ID is also in `reminderJobIds` renders
  `_SavedReminderSubtitle` with `reminderRowSubtitle(job: null, now: now, lang: lang)`
  (`K.reminderRowUnavailable`).

### Settings (`lib/features/settings/settings_screen.dart`)

- Added optional `preferences` and `repository` parameters to `SettingsScreen` while preserving the
  existing `SettingsScreen({super.key, required this.actions})` call contract for `lib/app/**`.
- Added `_StoredRemindersSummaryRow` inside the Notifications card displaying
  `K.storedReminderCount(reminderIds.length, lang)` and `storedRemindersSummarySubtitle(...)`.
- Tapping the summary row is a safe no-op (`onTap: () {}`, `minHeight: 48`) that navigates nowhere
  and performs no persistence or permission requests (ready for captain wiring).
